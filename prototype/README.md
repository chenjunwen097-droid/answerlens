# AnswerLens 新版交互原型

这是一个**纯本地静态原型**，用来评估新版的页面编排与交互，不连接真实模型。

```bash
npm run prototype
# → http://127.0.0.1:4173/prototype/
```

## 建议按这个顺序点

1. **首页**：三个建议卡片会填入输入框；底部是整个产品唯一的输入框
2. **发送**：输入框 → Agent 回复一张"准备开始检测"的确认卡
3. **开始检测**：右侧滑出进度面板，依次跑完 6 个阶段
4. **报告生成**：输入框左上角的 scope chip 变成「报告 · 小米 14」
5. **查看完整报告**：报告在主栏打开，输入框仍然在底部（没有第二个输入框）
6. **在报告里提问**：输入「第 2 题为什么得分低？」→ 右侧变成「报告对话」，只显示这份报告的线程
7. **报告库**：左栏切换，支持分数筛选；打开任意报告，scope 自动跟随
8. **⌘K / Ctrl+K**：命令面板，可搜索报告

## 这个原型验证的设计点

- 同一时刻页面里**只有一个 composer**（`#composer` 计数恒为 1）
- 报告问答不新开输入框，而是切换输入框的作用域
- 报告是资源，不是 agent：切换报告不会新建 agent
- 模块切换、面板打开、消息入场、分数环、对比条都有动效，并尊重 `prefers-reduced-motion`

## 和最终实现的差距

- 所有数据是 mock，分析流程用定时器模拟
- 没有后端、账号、持久化
- 报告问答的回复是模板，不是真实模型输出
- 移动端把右侧面板做成底部抽屉，保证输入框始终可达
